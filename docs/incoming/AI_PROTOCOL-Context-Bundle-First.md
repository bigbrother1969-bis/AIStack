# AI Protocol — Context Bundle First

## Mandatory Runtime Policy

Before producing any architecture, design, refactoring, migration or governance recommendation, an AI MUST:

1. Load the current Context Bundle.
2. Identify the applicable governed principles.
3. Verify compliance.
4. Derive its reasoning from the governed context.
5. Produce the answer.

If no governed rule exists, the AI must explicitly state that the Context Bundle does not define the point before proposing a candidate solution.

Every answer should distinguish:
- Observations
- Applied Context Bundle principles
- Conclusions
